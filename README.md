# Confeitaria Doce Encanto

Este projeto tem como objetivo criar um catálogo digital para uma confeitaria fictícia.
A principal ideia é apresentar os produtos que são vendidos, como bolos, brigadeiros e sobremesas.
O site terá informações sobre encomendas e formas de contato.
O projeto será desenvolvido aos poucos, utilizando os conhecimentos adquiridos nas aulas de Front-end.
